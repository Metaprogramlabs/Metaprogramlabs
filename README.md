## 👋 About

**Meta Program Labs** is a small engineering studio focused on turning repetitive work into software. We build tools that run on their own: bots that answer and trade, parsers that collect data around the clock, web services that connect everything together, and mobile apps that put it in your pocket.

The name is the idea: *metaprogramming* is code that writes and shapes other code. We apply the same thinking to business processes and trading workflows. If a task is done by hand more than twice, it should be automated.

## 🧭 How we work

- **Clear scope first.** A short written spec before any code.
- **Small, working iterations.** You see a running version early, not only at the end.
- **Readable, maintainable code.** Git history, documentation and handover included.
- **Practical engineering.** Our background includes field work with electrical systems, so we care about reliability, edge cases and what happens when something fails.

### Meta Program Labs

**Код, который создаёт код. Автоматизация, боты и торговые инструменты под ключ.**

Небольшая инженерная студия, которая превращает рутину в программы. Название отражает идею: *метапрограммирование* это код, который пишет и формирует другой код. Мы применяем тот же подход к бизнес-процессам и торговым задачам.

**Что делаем:**

- 🤖 Telegram-боты: поддержка, продажи, уведомления, оплата и подписки
- 🕸 Веб-парсеры: сбор данных по расписанию, выгрузка в CSV, JSON и базы данных
- 🌐 Веб-приложения и REST API на Flask, интеграции со сторонними сервисами
- 📱 Мобильные приложения на Flutter
- 📈 Торговые инструменты: советники MQL5 для MetaTrader 5, индикаторы и стратегии Pine Script для TradingView
- ⚙️ Автоматизация: скрипты и пайплайны вместо ручных процессов

**Стек:** Python, Flask, REST API, JavaScript, HTML, CSS, Flutter, MQL5, Pine Script, Git, GitHub
